# HARU Social Website

A minimalist black/white/gray responsive social-media landing page.

## Included
- Responsive phone + PC layout
- TikTok, Instagram, Facebook links
- Discord username copy button
- Opening screen with Enter interaction
- Looping background music player
- Music on/off control
- No database or server required

## Add your music
Put your legally obtained MP3 file inside:

music/bounce-back.mp3

The website is already configured to play that file.

## Discord
The current button copies `not_jhb` because a Discord username alone is not a reliable public profile URL. If you have a Discord invite link or Discord user ID/profile link, replace the button with that link.

## Free hosting
This site can be hosted using GitHub Pages. Create a public repository named:

YOUR_GITHUB_USERNAME.github.io

Upload `index.html`, `style.css`, `script.js`, and the `music` folder, then enable GitHub Pages from the repository settings.
